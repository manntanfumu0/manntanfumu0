# 📌 Featured Projects

## 🏦 BNDES Analytics Engineering Pipeline

End-to-end **ELT pipeline** built with the **Modern Data Stack** to ingest, transform, and model public BNDES loan disbursement data on Google Cloud.

### Architecture

```text
BNDES CKAN API
       │
       ▼
Python + Docker
       │
       ▼
Google Cloud Storage
       │
       ▼
BigQuery
       │
       ▼
dbt Core
       │
       ▼
Looker Studio
```

### 🔑 Key Highlights

* Automated data ingestion from the **BNDES CKAN API**
* Containerized data extraction with **Docker**
* Data Lake architecture using **Google Cloud Storage**
* **BigQuery External Tables** for cost-efficient data access
* ELT transformations and **dimensional modeling with dbt**
* Automated **data quality validation** using dbt tests
* Interactive executive dashboard built with **Looker Studio**

### 🛠️ Tech Stack

**Python • Docker • Google Cloud Storage • BigQuery • dbt Core • Looker Studio**
